# IPv6 科研下载助手 0.7.0

原生 Windows EXE，直接打开桌面图标。保留 37 类科研来源与 Epic，默认不改变网络，启动接管后按选择的域名转发。

## 修复与新增

- DNS 每个服务有独立 3 秒预算，包含 CNAME 跟随；一次查询不再耗尽后备服务预算。
- 分开报告无 AAAA、NXDOMAIN、DNS 超时、连接超时、TLS、节点策略、HTTP 403/404/429、文件格式或哈希失败。每个来源显示处理建议和逐域名 DNS 证据。
- 重新检测会刷新相关 DNS 缓存；验证实际文件按钮打开下载页并载入公开样本。需要授权的文件仍由用户提供有效链接，不读取浏览器凭据。
- arXiv 使用 Fastly 双栈入口，原 URL、SNI、证书校验保持不变；上游列表显示实际解析域名，可固定或拉黑对应候选。此映射仅适用于 arxiv.org 与 export.arxiv.org。
- NOAA GOES-16 匿名 S3 文件可映射同一官方桶的双栈入口；签名链接不改写。浏览器 HTTPS 请求不会被解密改写，自动接管使用官方 dualstack 文件地址。
- 新增 bioRxiv、medRxiv、Figshare、ModelScope、IEEE、Wiley 文件样本，保留各项真实成功或失败。

## 实测结果（2026-09-30）

- 58 项 Go 测试（含子测试）通过，go vet 通过。
- 37 个科研来源：13 个样本通过、16 个未查到 IPv6、4 个需授权或网站验证、3 个需实际文件、1 个连接超时。
- 相对 0.6.0 新增通过：arXiv、bioRxiv、IEEE 公开作者稿、NOAA GOES 说明 PDF。样本通过不保证平台所有下载，部分样本只读文件片段。
- arXiv 完整 PDF 2,215,244 字节，独立 IPv6 请求与助手代理下载的 SHA256 一致；此为重复下载一致性，不是官方公布哈希。
- Epic 7 项回归通过：真实 UE 数据块 SHA256、解压大小、清单 SHA1；10 秒 TCP 采样 2 个 IPv6 远端、0 个 IPv4 远端。仅证明本次助手链路，不代表全机或 CDN 到源站的协议。
- 更新退出后原 Clash 配置 SHA256 与既有基线一致，测试后恢复 GitHub Raw 接管。

## 构建

使用 Go 和系统 .NET Framework：

```powershell
go test ./...
go vet ./...
go build -trimpath -ldflags "-s -w -H=windowsgui" -o output/IPv6Engine-0.7.0.exe .
powershell -NoProfile -ExecutionPolicy Bypass -File native/build.ps1
```

构建结果为 output/EpicIPv6Native.exe。详细公开构建方法见 ../DEVELOPMENT.md。
